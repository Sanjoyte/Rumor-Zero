# Approved implementation plans

Before implementing a `task.md` part, save the user-approved plan here as:

`part-<ID>-<short-title>.md`

Each plan must contain:

- part ID, scope and dependencies;
- assumptions and user decisions;
- files expected to change;
- ordered implementation steps;
- required tests and validation commands;
- explicit non-goals and stop conditions;
- approval date and approving user.

Do not treat an unapproved draft as executable. `docs/agents/HANDOFF.md` must point to the current
approved plan so Claude Code or Codex can continue it without relying on chat history.
